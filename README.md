# Dictastack

Dictée vocale pour Windows, par Paul Hugy (https://hugy.fr/).

Ce dépôt ne contient que les installeurs. Pour installer Dictastack, télécharge `Dictastack_..._x64-setup.exe` dans la dernière version, à droite sous **Releases**.

Une fois installée, l'appli propose elle-même ses mises à jour, en bas de sa fenêtre : elle lit `latest.json` ici, sans rien envoyer de tes dictées.
